# Task D — 모의 선반 보충 (과제 B 모의판)

> [← 메인 README 로 돌아가기](../README.md)

```bash
cd /workspace/cyclo_lab
${ISAACLAB_PATH}/_isaac_sim/python.sh -u /workspace/challenge_scripts/task_d_demo.py --seed 1000
```

태스크 D 는 **과제 B 의 모의판**입니다. 과제 B 를 그대로 두고 목표 선반만 바꿨습니다.
로봇은 빈손으로 서고, 채워 넣을 상품은 옆 검정 책상 위 파란 크레이트에 하나 들어 있습니다.

### 1. 환경 주요 요소

| 요소 | 치수·자리 | 비고 |
|---|---|---|
| **3 단 선반** | 900 × 400 × 760 mm, 앞면 x 0.470, −X 를 봄 | **판은 맨 위 한 장(윗면 0.759 m)뿐.** 1·2 단은 지지대만 남았고 판은 스테이지에서 지웠다 |
| **로봇** FFW-SG2 | 바닥 (−0.15, 0.0) | 섀시 앞면에서 선반 앞면까지 395 mm. 빈손이다 |
| **검정 책상** | 600 × 600 × 725 mm, (−0.15, −0.80), yaw −90° | 로봇과 x 가 같아 앞이 아니라 옆에 선다. 운동학 고정 |
| **파란 크레이트** | 380 × 590 × 140 mm, 책상 위, yaw 90° | 운동학 고정. 안쪽 바닥 0.7377 m, 림 0.8670 m |
| **선반 위 상품** | **5 개** | 3 열 × 앞뒤 2 줄 = 6 자리 중 한 자리가 빈다 |
| **크레이트 안 상품** | **1 개** | 빈 자리의 상품. 동역학(집어야 한다) |
| **배경 매장 기물** | 7 ~ 12 개 | 곤돌라·냉장 진열대·쇼케이스·계산대·바구니 등 17종에서 뽑는다 |
| **매장 바닥** | 13 × 13 m | 회색 격자 대신 매장 바닥 판 |

선반 높이 적층 (바닥 = 0, mm):

```
기둥 발굽      0 ~  10      바닥에 닿는 유일한 부재
1 단 지지대    35 ~  85      판 없음
2 단 지지대   394 ~ 444      판 없음
3 단 지지대   700 ~ 750
3 단 판       750 ~ 759      ← 상품이 서는 유일한 판. 900 × 400, 흰색, 무늬 없음
기둥           0 ~ 760
```

### 2. 자리 번호와 상품 명명

맨 위 판의 자리는 `(층, 자리)` 로 적습니다. 층은 **2**(맨 위) 하나뿐이고, 자리는
`앞줄 0·1·2`, `뒷줄 3·4·5` 입니다. 열 `c` 의 앞자리가 `c`, 뒷자리가 `c + 3` 입니다.

```
        0 열      1 열      2 열
뒷줄  [  3  ]  [  4  ]  [  5  ]
앞줄  [  0  ]  [  1  ]  [  2  ]      <- 빈 자리는 언제나 앞줄
```

프림 이름은 선반이 `L2_S00` ~ `L2_S05`, 크레이트가 `Crate0`, 배경이
`Clutter_00_<기물>` 입니다. 상품 이름은 과제 B 와 같은 슬러그(`pringles_original_small`,
`cocacola_zero` …)를 씁니다.

### 3. 환경 생성 파라미터 (`--seed`)

**한 장면을 정하는 것은 `--seed` 하나뿐입니다.** 규칙은 `scripts/taskD/taskD_scene_seed.py`
에 전부 있고, 그 파일만 읽으면 됩니다.

```
shelf_seed   = int(md5("taskD-eval-shelf|<seed>")[:8],   16) % 999999 + 1
crate_seed   = int(md5("taskD-eval-crate|<seed>")[:8],   16) % 999999 + 1
clutter_seed = int(md5("taskD-eval-clutter|<seed>")[:8], 16) % 999999 + 1
```

`random` 을 쓰지 않는 이유는 파이썬 판이 바뀌면 수열이 달라지고 다른 언어에서는 재현할
방법이 없기 때문입니다. md5 는 파이썬이 없어도, 손으로도 같은 값이 나옵니다.

| 씨앗이 정하는 것 | 바뀌는 것 |
|---|---|
| `shelf_seed` | 세 열의 상품, 그리고 **어느 열의 앞자리가 비는지** |
| `crate_seed` | 크레이트 안에서 상품이 놓이는 자리 |
| `clutter_seed` | 배경 기물의 종류·개수(7~12)·자리·각도 |

**빈 자리와 크레이트는 따로 뽑지 않습니다.** 빈 자리가 생긴 열의 상품이 그대로 크레이트에
들어갑니다 — 로봇이 채워야 하는 것이 바로 그 상품이므로 둘은 한 뽑기의 두 면입니다.

**자리는 안 바뀌고 물건만 바뀝니다.** 로봇·책상·크레이트·선반의 좌표는 씨앗과 무관해서
충돌 판정이 보는 발자국도 씨앗과 무관하고, 정책이 보는 그림만 매번 달라집니다.

| 깃발 | 무엇 |
|---|---|
| `--seed N` | 장면 하나를 정하는 수. 기본 1000 |
| `--seconds S` | 장면을 S 초 유지. 0 이면 창을 닫을 때까지 |
| `--settle S` | 보고 전에 물리를 S 초 돌린다. 기본 2 |
| `--shot FILE.png` | 로봇 머리 카메라가 보는 그림 한 장 |
| `--scene-json FILE.json` | 장면 내용을 JSON 으로 |
| `--no-clutter` | 배경 기물과 매장 바닥을 빼고 맨 장면만 |
| `--check` | 장면 규칙과 에셋만 검사하고 끝낸다. SimulationApp 을 띄우지 않아 1 초 |

#### 배경 기물이 작업물을 건드리지 않는다

배경 기물은 **운동학 고정**이라 겹쳐도 물리가 밀어내지 않고 조용히 파고듭니다. 눈으로는
틀렸고 로그로는 정상인 상태가 되므로 기하가 유일한 방어선입니다. 규칙 셋:

1. **작업영역 금지** — 로봇(실측 발자국 628 × 602 mm)·책상·크레이트·선반 네 상자에
   여유 **350 mm**. 상자는 `taskD_measured.json` 에서 **계산**합니다(손으로 적지 않습니다)
2. **카메라 눈에서 1.25 m 금지** — 없으면 렌즈 안에 냉장고가 생겨 화면이 텍스처 벽이 됩니다
3. **서로 겹침 금지** — 외접원으로 잽니다(yaw 를 일부러 비틀어 놓으므로)

어기는 추첨은 밀어내지 않고 **버리고 다시 뽑습니다.** 밀어내면 매번 선반에 딱 붙어 서게
되고 그것도 일종의 단서입니다. 매 실행마다 기물별 여유를 찍고 하나라도 0 이하면 멈춥니다.

### 4. Headless 모드를 활용한 빠른 데이터 추출

```bash
# 장면 내용만 파일로 (화면 없이)
${ISAACLAB_PATH}/_isaac_sim/python.sh -u /workspace/challenge_scripts/task_d_demo.py \
    --seed 1000 --headless --scene-json /workspace/user/scene_d_1000.json

# 머리 카메라 그림까지
${ISAACLAB_PATH}/_isaac_sim/python.sh -u /workspace/challenge_scripts/task_d_demo.py \
    --seed 7 --headless --shot /workspace/user/d7.png

# 씨앗을 훑는다 (한 씨앗에 프로세스 하나 -- 한 세션에서 장면을 다시 지으면 안 된다)
for s in 1000 1001 1002; do
  ${ISAACLAB_PATH}/_isaac_sim/python.sh -u /workspace/challenge_scripts/task_d_demo.py \
      --seed $s --headless --scene-json /workspace/user/scene_d_$s.json
done
```

**한 아이작 세션에서 장면을 다시 지으면 안 됩니다.** 씨앗을 여러 개 볼 때는 씨앗마다
프로세스를 새로 띄웁니다. 재사용하면 두 번째 장면에서 말없이 죽습니다.

`--scene-json` 이 내려 주는 것: 세 스트림 씨앗, 세 열의 상품, 빈 자리와 그 상품,
선반 5 개와 크레이트 1 개의 위치·자세, 배경 기물의 자리·각도, 그리고 고정 좌표.

### 7. 좌표계 정보

월드는 **+X 앞 / +Y 왼쪽 / +Z 위** 입니다(Isaac Lab 규약). 로봇은 원점 근처에서 **+X** 를
보고 서고, 선반은 그 앞 x 0.470 에서 **−X** 를 봅니다. 책상과 크레이트는 로봇의 **오른쪽**
(−Y) 입니다.

```
                     +X (로봇이 보는 쪽)
                      ↑
        선반  x 0.470 ~ 0.870,  y −0.450 ~ +0.450
                      │
   +Y ←──────────── 로봇 (−0.15, 0)  ──────────→ −Y
                      │
        책상  x −0.450 ~ 0.150,  y −1.100 ~ −0.500   (크레이트가 그 위)
```

선반 자리 좌표는 앞면 x 0.470 에서 **앞 여유 100 mm**, 앞뒤 간격 **140 mm**, 좌우 간격
**280 mm** 로 잡고, 상품마다 축당 **±5 mm** 안으로 밀어 놓습니다(진열은 자로 재어 놓지
않습니다). 전부 과제 B 의 값입니다.
